# 移动端阅读体验方案

> 更新：2026-08-23
> 目标：能正常阅读——手机端自适应（设备决定交互模式，非响应式缩放）

## 定位

阅读页（Read.tsx）达到"正常阅读"标准。范围收敛：**不做专业阅读器功能**（字体选择/划线笔记/设置面板/同步/社交全部不做）。

## 自适应策略（设备决定交互形态）

**不是响应式**（同一布局随宽度缩放）——是**自适应**（不同设备 = 不同阅读模式）：

| 设备 | 阅读模式 | 交互 |
|------|---------|------|
| **手机/平板** | **分页模式** | 正文分页 + 左右滑动翻页 + 翻页进度 |
| **桌面** | **滚动模式** | 连续滚动 + 限宽排版（网页惯例） |

### 设备检测

```ts
// 触摸优先 = 移动端 → 分页模式
const isTouch = window.matchMedia('(pointer: coarse)').matches
// 渲染：{isTouch ? <PagedReader /> : <ScrollReader />}
```

### 分页模式（手机）

- 正文按页分片（scroll-snap 或 JS 翻页）
- 左右滑动翻页（**必须项**——手机阅读核心交互）
- 翻页进度（第 X 页 / 共 Y 页）

### 滚动模式（桌面）

- 现有连续滚动 + 限宽排版（45rem 居中）

## 排版（两模式共用基础）

- 字号 17px 基准（手机）/ 18px（桌面）、行高 1.9
- 首行缩进 2em（中文惯例）、段落间距
- safe-area 适配（env(safe-area-inset-*)——刘海屏/底部横条）

## 进度缓存（localStorage，两模式共用）

- key：`qtfiction.progress.v1`，按系列分组：`{ 系列id: { file, page, updatedAt } }`
- 手机 page = 页码；桌面 page = 滚动百分比
- 写入：翻页/章节切换（防抖 300ms）+ 卸载兜底
- 读取：Read 页直接打开记录章节 + 位置；系列页显示"继续阅读"入口
- 封装 `src/data/progress.ts`（get/save，try/catch 容错）
