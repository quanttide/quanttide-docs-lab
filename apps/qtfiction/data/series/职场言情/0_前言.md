# 前言

有天晚上，我在便利店写完了男女主久别重逢后的第一次谈心。

他们坐在靠窗的位置，各捧一杯关东煮。窗外是淅淅沥沥的小雨，窗内是一对各怀心事的年轻人。

那个情节我写了很久，也改了很久，因为太多话想借着他们的口说出来。

他们是我在现实世界的投射。我在各种尝试中持续地茫然，被现实的压力推着往前走，常常不知道自己在什么位置。

写小说这件事慢慢变成了一个持续补充心力的安全空间。

每当夜晚的恐惧漫上来，害怕一切不会好起来，害怕心里的话永远说不出口，我就回到这个虚构的世界里，写一点，再写一点。

这个故事的设定是一个典型的母题：双向暗恋、久别重逢。

但在最关键的走向上，我刻意回避了“破镜重圆”。从现实来看，这种几乎不讲道理的等待并不存在，所以我用一个近乎科幻的设定来承载它。

正是这份不讲道理，成了整部小说最大的悬念——他们凭什么还能记住彼此？他们为什么愿意等十年？

我渐渐发现，我想写的故事是：我们不需要回到过去，我们现在就可以重新认识一次。

写作的过程，比我想象中更诚实地改变了我。

我原本计划写他们重逢时是欢快的，但写着写着，环境变热闹了，氛围反而变得文艺。我慢慢明白，情绪不一定要和环境正相关，也可以相反。

就像现实里说不出口的那些烦恼——不敢说，不敢写，也不相信有人能理解——当它们被放进故事里，被男女主的对话承接住，反而获得了某种自由。

我在这部小说里放了很多真实的东西。

“瓶子”这个意象，来自一个曾经有过纠缠的女孩。那不是一个愉快的经历，但那个形容太深刻了，深刻到我不知道该怎么写。于是我把这些感受写下来，先让自己看到这些情绪的形状。

后来我才明白，释怀是故事有了不同的意义，而我可以继续向前，而不是让情绪停留在原地。

那段十年重逢，是我想让男女主去完成的执念——我曾经有过的，大概很多人也有过的，那种被看见的渴望。

写着写着，我发现各种心结其实是可以借由人物写出来的。他们经历的波折，是可迁移的情绪。设定影响了情节，而情节反过来启发我在现实世界里积极行动。

我越来越敢去触碰那些更深的主题，也越来越多地把真实的幽微感受放进故事里。那些故事设定的治愈感，为琐碎的困扰提供了出口。

每一次写完，把段落读出来，那些焦虑就随之放下了。

这部小说不是一座可以装下一生的容器。它装下的只是我写作这半年来的困惑、恐惧、孤独与勇气。

小说里的十年，是我回顾过去的十年。十年之前是意气风发，十年之后是无数的现实压力在困扰，像极了故事里的男女主。

我选择把真实的职场体悟写进男女主的人设里，是因为他们的故事原本就有一部分继承自我的意志。

那些无法公开表达的情绪，被我放进了更隐晦的批评、更直白的感受里。它们会成为公司的故事，成为品牌故事的一部分，因为这里也是我现实世界的延伸。

写作教会我的最重要一件事是：把不敢说的，变成可以说的。

我依然渴望写出更具爆发力的片段，能够直接击中心底的某个地方；让那些想说出口的话终于可以说出口，让那些困扰已久的问题被消解；或者仅仅是多获得一些勇气，去承载更多的重量，学会保持边界。

因此这本书会继续写下去。男女主会一步一步靠近彼此，情节会继续生长。不是因为我已经找到了所有答案，而是因为我发现了写作本身的答案——当你把故事讲得足够真诚，它就会反过来照亮你前行的路。

这不仅仅是一部小说。

这是一个人决定不再停留在原地，也是一家公司把“敢说”写进自己底色的开始。
