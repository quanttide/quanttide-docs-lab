# Changelog

本文件记录量潮小说（qtfiction）的所有重要变更。

## [0.1.0-alpha.2] - 2026-08-23

### Added

- 阅读自适应：手机分页模式（正文分页 + 左右滑动翻页 + 页码指示），桌面滚动模式（连续滚动 + 限宽排版）
- 阅读进度缓存（localStorage）：按系列记住最近章节与位置，系列页"继续阅读"入口，Read 页自动恢复
- 排版优化：字号 17/18px、行高 1.9、首行缩进 2em、safe-area 适配（刘海屏/底部横条）

## [0.1.0-alpha.1] - 2026-08-23

### Added

- 小说发布平台初始化：React + Vite + TypeScript 站点
- 数据模型 `src/data/series.ts`：从 `data/series/<系列>/<编号_标题>.md` 读取正文，按系列与编号组织
- 页面：首页（系列入口）、系列页（章节列表）、阅读页（正文 + 上一篇/下一篇）
- 数据同步脚本 `scripts/sync-data.sh`：从 `assets/fiction` 同步小说正文
- 收录三个系列：职场言情（短篇合集）、校园言情（章节长篇）、重生言情
